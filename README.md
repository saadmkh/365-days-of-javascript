## 🚀 Daily JavaScript Challenges

Solving **at least one JavaScript task every day** to build consistency, improve problem-solving skills and master JavaScript from fundamentals to advanced concepts.

No zero days. Just progress.

---

## 📌 Goals
- Build a strong JavaScript foundation
- Improve logical thinking & problem-solving
- Stay consistent with daily coding
- Prepare for interviews & real-world development

---

## 🗂️ Repository Structure
day-01/
└── task.js

day-02/
└── script.js

day-03/
└── index.html
└── style.css

...



Each folder contains:
- The problem statement (as comments)
- The JavaScript solution
- Optional edge cases or optimizations

## 🧠 Topics Covered
- JavaScript Basics
- Arrays & Strings
- Objects & Functions
- Loops & Recursion
- ES6+ Features
- Asynchronous JavaScript
- DOM Manipulation
- Algorithms & Data Structures
- Interview-style Problems

## 🔥 Rules I Follow

- 🔁 Refactor old solutions when I learn better approaches
